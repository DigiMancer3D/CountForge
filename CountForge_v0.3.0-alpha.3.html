Reversible binary transition (BTT)

First bit unchanged; subsequent bits are XOR of adjacent original bits. The inverse uses cumulative XOR. This is a transform, never encryption.

Experiment board

Ideas kept deliberately separate from the trusted inventory ledger:

Carry / 3-point / 4-point

Unit quantities use mixed-radix carry normalization. A case means packs × singles per pack, and a pallet means cases × packs × singles per pack.

Compact recipe candidates

Export compares actual byte sizes of plain vs dictionary-indexed records, with optional gzip. A candidate is chosen only if it is smaller and can be decoded exactly. SPX/CFTT/MRPS compression claims are intentionally not assumed.

HUD / field map

The old pill HUD inspired the grab-and-pin interface. The old bi-sectional grid inspired the selectable 9×9 catalog map rather than being transplanted as unverified inventory logic.

Connected exports
